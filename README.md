# 荒野求生：失落边境 v33

## 本版重点

- 继续使用 v32 的 `AssetManager` 图片资产映射与缺图兜底机制。
- 新增四名角色的首版方向/步行动画图集：`images/characters/{scout|medic|mechanic|hunter}_walk.png`。
- 角色图集采用 **4 列 × 4 行**，每格 **64 × 80 px**，整张图 **256 × 320 px**；行顺序为 `down / left / right / up`，列为步行动画帧 0–3。
- 如果删除或替换步行动画图集，程序会自动回退到同名静态角色图（例如 `scout.png`），可选动画缺失不会刷屏或导致黑屏。
- 世界地图相机采用基于帧时间的指数平滑插值；移除了手动跳过部分 `requestAnimationFrame` 帧的节流逻辑。
- 世界自然物件与玩家改为按世界坐标脚点 Y 值排序；可通过对象的 `depthY` 字段微调特殊物件脚点。
- 限制单帧模拟时间差，避免窗口切回或卡顿后玩家瞬移。
- 保留 v32 原有交互、采集、战斗、天气、室内场景、存档与 UI。

## 图片替换规范

| 资产 | 路径 | 推荐尺寸/规则 |
|---|---|---|
| 角色静态图 | `images/characters/scout.png` 等 | 64×80，透明 PNG，脚底居中 |
| 角色步行图集 | `images/characters/scout_walk.png` 等 | 256×320；4×4 网格，每帧 64×80 |
| 地表 | `images/tiles/*.png` | 32×32，可平铺 |
| 树木/植被/岩石 | `images/environment/*.png` | 透明 PNG，画布底部对齐脚点 |
| 道具图标 | `images/items/*.png` | 32×32 或 48×48，透明 PNG |
| 地标 | `images/landmarks/*.png` | 按原对象占地比例，透明 PNG |

建议所有可行走对象的脚底/接地位置在图片底部中间附近；树冠等上半部可以向上延伸，但不要把透明边距误当作脚点。更换素材时保持文件名不变即可，不需要改 JS。

## 运行

1. 解压本 ZIP。
2. 如果你自己的原项目有 `images/title-bg.png`，将原图复制到 `images/`，不要覆盖或重画原始标题背景。
3. 使用浏览器打开 `index.html`。
4. 如果你自行替换素材，保留上表的文件名与图集规格即可。

- 首版角色图集由现有占位角色图程序化整理，方向与步态是可替换的初版素材，不等于最终专业美术动画。可以直接用自己找的同规格图集覆盖。

## v34：全物品图标图片化

新增 `images/items/icons/`，为游戏物品目录中的 89 种物品生成了第一版独立 PNG 图标，并将背包/快捷栏图标、配方输出图标和世界掉落物图标接入图片加载。图标是可替换的占位像素图，后续可以用同名 PNG 覆盖。

- 图标路径：`images/items/icons/{物品ID}.png`，例如 `images/items/icons/medkit.png`、`images/items/icons/ironOre.png`、`images/items/icons/campKit.png`。
- 建议统一使用 48×48 RGBA PNG，主体居中并保留透明背景。
- 某张图标缺失时，UI 会回退到原 emoji 图标；世界掉落物也保留文字/emoji 兜底。
- 原有角色、地面、环境、地标和步行动画素材仍保留。标题界面文件未修改。

## v40 更新（飞机碰撞轮廓与动态怪物）
- 飞机残骸不再用整块矩形地块碰撞；碰撞只覆盖机身外沿，凹口和南侧入口保留通行空间，减少贴图透明/凹陷区域卡脚。
- 初始怪物数量提高：白天 4 只、夜晚 6 只；初始与后续刷新点均随机抽取，并检查距离、地形和飞机入口附近的禁刷区域。
- 白天与夜晚分别使用不同的刷新间隔、数量上限和物种倾向；怪物属性统一按生存天数升级，每过一天提升约 12% 生命与伤害、约 3.5% 移动速度，最多叠加 10 阶。已有怪物也会随阶段同步变强。
- 旧存档读取时会按当前游戏天数同步怪物难度。
